# Ditter Board Prototype

A small, browser-based Treasure-Stealing Ditter prototype set at the Royal
Academy training grounds. Guide two apprentice knights across the arena to
capture the summoned feybeast treasure on the marked center tile.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Rules

- Select either apprentice knight, then choose one of the highlighted adjacent tiles.
- Pieces cannot move diagonally or onto each other.
- The match ends when either knight reaches the marked treasure tile.
- Use **Reset match** to return the knights to their starting positions.
